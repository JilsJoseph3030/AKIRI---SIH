# How Akiri features work

Snap and Lot: the collector photographs scrap, the classifier suggests a material category (CRT, LCD panel, PCB, cable, battery, motor or magnet assembly, mixed plastics), then weight entry shows an instant estimated value.

Price Board: current per-kg buying rates by material and location, cached offline, with audio playback in Marathi, Hindi, or English.

Recycler Match: ranks nearby authorized recyclers by distance, offered rate, pickup availability, and authorization status. Unauthorized facilities never appear.

Trust Ledger: each handover writes a hash-chained entry with a short reference code the recycler uses to confirm. Confirming seals the chain on both sides.

Earnings Ledger: running totals, pending dues, and history, readable offline.

Safety Guidance: pictorial cards with audio narration for batteries, CRTs, and a strict no-open-burning rule.

Payments default to cash. Digital payment is an optional toggle and never required.
