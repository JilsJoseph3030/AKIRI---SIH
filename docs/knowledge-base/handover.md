# Confirming a handover

Open the recycler dashboard lot queue, find the incoming lot by its photo, weight, and reference code. Verify the physical material matches the photo and category, then tap confirm handover. This writes a recycler-signed confirmation chained to the collector's entry, sealing the trust ledger on both sides once devices sync. If anything does not match, reject the lot and ask the collector to re-weigh or re-photograph.
