# Troubleshooting and FAQ

Lots not syncing: check connectivity; queued lots flush automatically when the network returns. Wrong category: re-run classification or pick the category manually before weighing. Reference code rejected: confirm the exact code from the collector's ledger screen, including order. App running slow on entry-level phones: close other apps; the app lazy-loads screens to stay lean. For account, payout, or compliance questions beyond these notes, contact the Akiri support channel from the dashboard About panel and a human will help.
